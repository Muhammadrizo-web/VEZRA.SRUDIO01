# Vezra Studio — сайт

Статический многостраничный сайт студии (RU). Собирается из шаблонов Jinja2.

## Запуск

Нужны Node.js и Python 3 (при установке Python — галочка «Add to PATH»).

```bash
npm run dev     # http://localhost:3000, пересборка и автообновление при правках
npm run build   # только собрать
```

Библиотеки Python (jinja2, pillow) скрипт поставит сам при первом запуске.

- `preview/` — готовые страницы, именно эту папку загружать на хостинг.
- `dist/` — то же, но index.html без `<!doctype>` (для публикации артефактом).

## Языки

Сайт собирается на трёх языках: русский — в корне, английский — в `en/`, узбекский (латиница) — в `uz/`.
Переключатель RU · EN · UZ в шапке ведёт на ту же страницу на другом языке.

- Тексты пишутся в шаблонах на русском. Переводы лежат в `i18n/en.json` и `i18n/uz.json`:
  ключ — русская строка как на странице, значение — перевод.
- Добавили или изменили русский текст → при сборке появится `i18n/_missing-en.txt` / `_missing-uz.txt`
  со строками без перевода. Добавьте их в json и пересоберите. Пока перевода нет, на странице остаётся русский текст.
- `i18n/_source.py` — все три языка рядом в одном файле; `python i18n/_source.py` заново создаёт оба json.

## Где что

| Что | Где |
|---|---|
| Контакты, цены, сроки, команда, бренды | `site.json` |
| Переводы EN / UZ | `i18n/en.json`, `i18n/uz.json` |
| Страницы | `templates/pages/` |
| Текст кейсов («Задача» / «Что сделали») | `templates/cases/` |
| Общая шапка/подвал | `templates/base.html` |
| Стили и скрипт | `src/` |
| Скриншоты кейсов | `site/img/` |

## Что заполнить в `site.json` перед запуском

`null` = данных нет: блок скрывается или показывается запасной текст.

- `studio.telegram` — ник без `@`. Пока пусто, все кнопки ведут в Direct Instagram `@vezra_studio`;
  как только ник указан, кнопки становятся «Написать в Telegram» с готовым текстом сообщения.
- `studio.phone`, `studio.email` — появятся в подвале и в финальном блоке.
- `prices.*` — числом в сумах (`1500000`), на сайте станет «от 1 500 000 сум».
- `team[].first/last/photo` — имена и фото (фото кладите в `site/img/`).
- `brands[].logo` — логотипы брендов для бегущей строки (файл в `site/img/`).
- `cases.*.days`, `cases.*.url` — сроки и ссылки на сайты кейсов.

Старые статичные версии страниц кейсов лежат в `templates/_archive/` и в сборке не участвуют.
